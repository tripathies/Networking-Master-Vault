Complete projects in increasing architectural complexity. Each should include requirements, assumptions, topology, IP plan, security matrix, configuration or IaC, validation evidence, failure tests, operations runbook and lifecycle notes.

6. [Global Application Delivery](projects/06-global-application-delivery.md)

## Definition of done
Another engineer can understand the requirements, reproduce the design in a safe lab, validate traffic paths, understand failure modes and operate the solution using the documentation.
