## Learning checklist

- [ ] [Network Monitoring and Observability](../../services/network-monitoring.md) — Collect availability, interface, flow, path and experience telemetry.
- [ ] [Wireshark](../../services/wireshark.md) — Inspect packet captures to diagnose protocol behavior and faults.
- [ ] [tcpdump](../../services/tcpdump.md) — Capture and filter packets from Linux and network interfaces.
- [ ] [NetFlow, IPFIX and sFlow](../../services/netflow-sflow.md) — Analyze traffic conversations, volume, sources and destinations.
- [ ] [Network Automation with Ansible and APIs](../../services/network-automation.md) — Automate repeatable configuration, validation and operational workflows.
- [ ] [Network Infrastructure as Code](../../services/infrastructure-as-code-networking.md) — Version and deploy network resources using Terraform and provider-native IaC.
- [ ] [Network Troubleshooting Methodology](../../services/network-troubleshooting.md) — Isolate faults systematically from physical layer through application.
- [ ] [MTU, MSS and Fragmentation](../../services/mtu-mss-fragmentation.md) — Understand packet sizing, path MTU discovery and fragmentation symptoms.
- [ ] [Network High Availability and Failover](../../services/high-availability-failover.md) — Design resilient paths, devices and services with tested recovery behavior.
- [ ] [Enterprise Network Design Patterns](../../services/enterprise-network-design.md) — Apply campus, data center, WAN, hub-spoke, spine-leaf and multi-region patterns.

## Completion standard

A topic is complete when you can explain its purpose and trade-offs, draw its traffic flow, configure or inspect it in a safe lab, validate expected behavior, troubleshoot one failure, and explain where it fits in an enterprise design.

## Suggested lab evidence

Record objective, topology, addressing, configuration, expected result, observed result, failure injection, troubleshooting steps, screenshots or sanitized command output, cleanup and lessons learned.
