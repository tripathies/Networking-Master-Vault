## Learning checklist

- [ ] [Security Zones and Segmentation](../../services/security-zones-segmentation.md) — Separate workloads by trust level, function and required communication.
- [ ] [Stateful and Stateless Firewalls](../../services/stateful-stateless-firewalls.md) — Compare connection-aware inspection with packet-rule filtering.
- [ ] [Network ACLs](../../services/network-acls.md) — Apply ordered allow/deny rules at interfaces, subnets or network boundaries.
- [ ] [NAT and PAT](../../services/nat-pat.md) — Translate addresses and ports between private and external network domains.
- [ ] [Site-to-Site VPN](../../services/site-to-site-vpn.md) — Securely connect networks over untrusted transport using IPsec or managed VPN.
- [ ] [Remote-Access VPN](../../services/remote-access-vpn.md) — Provide authenticated user or device access to private resources.
- [ ] [IPsec Architecture](../../services/ipsec.md) — Protect IP traffic using security associations, encryption and integrity.
- [ ] [IDS and IPS](../../services/ids-ips.md) — Detect or prevent suspicious network activity through signatures and behavior.
- [ ] [Zero Trust and ZTNA](../../services/zero-trust-network-access.md) — Grant access based on identity, device posture, context and least privilege.
- [ ] [DDoS Protection](../../services/ddos-protection.md) — Absorb, filter and mitigate volumetric and application-layer attacks.

## Completion standard

A topic is complete when you can explain its purpose and trade-offs, draw its traffic flow, configure or inspect it in a safe lab, validate expected behavior, troubleshoot one failure, and explain where it fits in an enterprise design.

## Suggested lab evidence

Record objective, topology, addressing, configuration, expected result, observed result, failure injection, troubleshooting steps, screenshots or sanitized command output, cleanup and lessons learned.
