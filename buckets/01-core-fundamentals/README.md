## Learning checklist

- [ ] [OSI Model](../../services/osi-model.md) — A seven-layer reference model for understanding how network communication is divided into functions.
- [ ] [TCP/IP Model](../../services/tcp-ip-model.md) — The practical protocol suite and layered model used by modern IP networks.
- [ ] [Ethernet](../../services/ethernet.md) — The family of wired LAN technologies defining framing, addressing and link operation.
- [ ] [Wi-Fi](../../services/wi-fi.md) — Wireless LAN technologies, radio bands, channels, roaming and security.
- [ ] [Network Types: LAN, WAN, MAN and PAN](../../services/network-types.md) — Classifies networks by geographic scope, ownership and connectivity.
- [ ] [Network Topologies](../../services/network-topologies.md) — Physical and logical layouts such as star, mesh, spine-leaf and hybrid.
- [ ] [Encapsulation and Decapsulation](../../services/encapsulation.md) — How application data is wrapped into transport segments, packets, frames and bits.
- [ ] [MAC Addressing](../../services/mac-addressing.md) — Layer 2 hardware addressing used for local-link frame delivery.
- [ ] [Network Interface Cards](../../services/network-interfaces.md) — Physical and virtual interfaces that connect hosts to networks.
- [ ] [Bandwidth, Latency, Throughput and Jitter](../../services/bandwidth-latency-throughput.md) — The core measures used to describe network capacity and user experience.

## Completion standard

A topic is complete when you can explain its purpose and trade-offs, draw its traffic flow, configure or inspect it in a safe lab, validate expected behavior, troubleshoot one failure, and explain where it fits in an enterprise design.

## Suggested lab evidence

Record objective, topology, addressing, configuration, expected result, observed result, failure injection, troubleshooting steps, screenshots or sanitized command output, cleanup and lessons learned.
