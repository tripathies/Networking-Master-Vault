## Learning checklist

- [ ] [Routing Tables and Longest Prefix Match](../../services/routing-tables.md) — Select next hops using destination prefixes and route preference.
- [ ] [Static Routing](../../services/static-routing.md) — Configure explicit routes for predictable and small-scale network paths.
- [ ] [Default Routes](../../services/default-routing.md) — Forward traffic when no more-specific route matches.

- [ ] [OSPF](../../services/ospf.md) — Link-state interior gateway protocol using areas and shortest-path calculation.
- [ ] [BGP](../../services/bgp.md) — Policy-driven path-vector routing between autonomous systems and within large networks.
- [ ] [EIGRP](../../services/eigrp.md) — Advanced distance-vector routing protocol and its operational concepts.
- [ ] [Equal-Cost Multi-Path Routing](../../services/ecmp.md) — Use multiple equal-cost next hops for load sharing and resilience.
- [ ] [Route Redistribution](../../services/route-redistribution.md) — Exchange routes between routing protocols with controls against loops.
- [ ] [VRF and Route Summarization](../../services/vrf-route-summarization.md) — Separate routing tables and aggregate prefixes for scalable design.
